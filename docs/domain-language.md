# Campus Cats

Campus Cats coordinates club members, field reports, cat catalogs, and feeding-station operations for university clubs. Each club's data and administration are isolated within its own tenant.

## Language

**Comment**:
A message attached to one sighting, catalog entry, or feeding station. Comments are
either authored inside Campus Cats or imported read-only from an attributed external
source.
_Avoid_: Note, reply

**Imported comment**:
A source-attributed iNaturalist comment synchronized with an imported sighting. It can
be hidden from Campus Cats by an officer but is never edited, removed from, or treated
as user discipline on iNaturalist.
_Avoid_: Local comment, member comment

**Disciplinary notice**:
A warning recorded on a member account by an officer, with a reason that becomes part of the account's moderation history.
_Avoid_: Strike, comment warning

**Ban**:
An account-wide suspension that prevents a member from signing in or accessing club data until an authorized officer removes it.
_Avoid_: Comment ban, mute
